# HCI / high-DPI checklist (M6)

> **中文主文档**：[../zh/hci-dpi-checklist.md](../zh/hci-dpi-checklist.md)

Run `qfr_demo` on Windows at **100% and ≥150%** scale, across Fluent Light / Dark / **High Contrast**.

Verify: QAT/tabs/panel layout, Simplified mode, Backstage alignment, KeyTips, ScreenTips, collapse tiers, group launcher, in-ribbon Gallery, and that `ribbon.*` colors track the QTE hc pack (no light-only hardcodes).
